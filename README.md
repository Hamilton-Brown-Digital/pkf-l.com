# PKF-L Accounting Systems Campaign page (2026)

This theme was developed in _Visual Studio Code_ with the following extensions:

- Live Sass Compiler v6.1.2 (https://marketplace.visualstudio.com/items?itemName=glenn2223.live-sass)
- JS & CSS Minifier v3.3.3 (https://marketplace.visualstudio.com/items?itemName=olback.es6-css-minify)


## Requirements

- SASS (https://sass-lang.com/)
- jQuery (https://jquery.com/)
- ScrollMagic (https://scrollmagic.io/)
- Flickity v2 (https://flickity.metafizzy.co/)


## Imported Scripts
- Code has been imported from the PKF website to use as a template. CSS has been namespaced to not conflict with the site.


## Setup

If you are making changes, the `assets/src` directory contains working SASS and JS files. If you're using the _Live Sass Compiler_ and _JS & CSS Minifier_ plugins, setting are applied in `.vscode/settings.json`.


## Deploy

Deployed CSS and JS files are contained within in the `assets/dist` directory. You do not need to include the `assets/src` or `assets/.vscode` directory for deployment.
